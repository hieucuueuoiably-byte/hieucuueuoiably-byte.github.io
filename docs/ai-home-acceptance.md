# AI 动态首页 · 2026-10-01

当前三个角色已按用户要求改成代码绘制，详情见 [代码重绘记录](home-code-redraw/README.md)。以下为首次接入的历史验收；角色抠图和旧着色器形变均已被代码关节替代。此前的遮罩修复记录保留在 [破面修复记录](home-art-repair/README.md)。

把用户批准的 `public/home-ai/hero-v5.png` 接成实际动态首页。最终配色是蓝紫外景、橙色内景和粉色前景云。未为这轮代码接入重新生成图片。

## 实现

- `HomeAiScene.ts`：七张注册透明图层，共用作品目录的 Three.js renderer/canvas；人物、气球、云分别定位和动画。代码胶片曲线、气球绳和闪光点独立渲染。
- `HomeAiShaders.ts`：96×54 分段网格的手臂、触手、鸟头加权形变；眨眼与镜头快门；GPU 流体位移、轻微色边和点击径向波纹。
- `HomeAiStage.ts`：绘制舞台、城市、灯架、底座；补足连续的鸟颈和麦克风杆。代码背景避免人物摆动后露出原图里重复的人像。
- `HomeFluid.ts`：复用项目已有的压力投影流体实现，模拟分辨率 64、密度分辨率 256、三次压力迭代。
- `HomePage.tsx`：保留真实 DOM 标题、导航和按钮；静态降级使用批准的完整图。首页与作品仍通过两个渲染目标完成转场。

运行时没有导入旧 `HomeScene.ts`、`HomeOriginalShaders.ts` 或参考站人物图集。旧文件及其来源记录保留供历史查阅。

## 边界

人物纹理由 AI 插画的可见部分提取，使用小幅加权形变与部件姿态；不是完整骨骼角色，也没有声称恢复被遮挡的隐藏图层。橙色舞台与城市是代码重绘，因此与静态源图的城市细节不同。流体机制复用项目既有实现，人物、场景与新合成 shader 是这轮新增。

减少动态效果分支经代码检查：停止流体、姿态、点击波纹、弹性入场与按钮镜头，并沿用已有系统媒体查询监听。浏览器本轮未切换操作系统减少动态设置；WebGL 缺失降级同样属于代码检查。本轮没有采集跨设备帧率或声称与参考站逐像素相同。

证据目录：`docs/ai-home-review/`。素材出处与生成修订见 `public/home-ai/README.md`；遮罩可通过 `scripts/prepare_home_ai_layers.py` 重建。
