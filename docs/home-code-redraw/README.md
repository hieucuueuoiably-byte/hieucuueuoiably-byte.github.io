# 首页角色代码重绘

按用户要求，将三个自有角色改为纯色代码绘制，并仿照原站的分件图集结构实现动作。v5 角色轮廓、半睁眼、帽子、镜头、触手吸盘、耳机、设备包和麦克风转换为曲线路径，以固定色板填充和黑色描边绘制。网页通过 Path2D 生成自己的透明图集。

`src/data/home-character-paths.json` 存储路径与配色，`scripts/trace_home_characters.py` 可从选定图离线重建。来源是用户已批准的自有生成图及其注册图层，未使用参考站的角色素材。脚本移除小面积游离墨点、闭合细小透明缺口，保留手臂和腿之间的大面积负空间。

检查了 `https://ponpon-mania.com/fr` 的实际首页、单个 WebGL canvas，以及本地保存的原站图集与 GLSL。原站使用透明手绘图集：中央角色身体加眼睛，侧面角色身体/头/手臂/道具分件；局部 UV 动作与关节转动组合。详细原站坐标仍见 `../reference-home-mechanism.md`。当前角色采用这一构造方式，角色内容继续使用自己的摄影机导演、章鱼和收音师。

`src/gl/HomeCodeCharacters.ts` 在初始化时以 2 倍分辨率绘制曲线，装配 15 个透明部件（包含身体与关节衔接片）。摄影机双臂和围巾、章鱼触手、鸟的收音杆/手和三个头部分别摆动；关节衔接片保留相同位置的原始曲线颜色。头部轻微 UV 呼吸。头部图集共 6 个状态帧：章鱼与鸟的开/闭眼、摄影机镜头的开/闭快门。闭眼帧保留透明度，只改眼部色块；着色器切换 atlas cell。静态降级复用同一份曲线绘制。
