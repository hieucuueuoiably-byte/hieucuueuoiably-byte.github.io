# 首页 v7 · 更强透视与原站粒子

用户反馈 v6 的立体运动太轻微。本轮扩大相机运动，并将原站的三套粒子接入当前自有角色首页，未重新制作角色图片。

## 空间运动

| 项目 | v6 | v7 |
| --- | --- | --- |
| 桌面横向相机幅度 | 140 | 320 |
| 桌面纵向相机幅度 | 80 | 170 |
| 桌面注视点偏移 | (8,4) | (100,-65) |
| 角色深度 | (0,135,220) | (0,260,360) |
| 城市 / 远景云深度 | -650 / -950 | -1000 / -1600 |
| CTA hover | fov 45→42，推进 3.5% | fov 45→40，推进 7.5% |

相机位移约为此前的 2.3 倍，实际旋转幅度还受到注视点偏移影响。三个角色的整体平面增加轻微 Y 转动，底座有独立 X/Y 倾斜；使用真正的透视投影与深度补偿。手机使用较小的 95/65 位移与 25/-18 注视点偏移，触屏松手时复位镜头。

红色地面从城市纹理中拆出，置于 z=-100 的独立层。地面画布向下延伸到 1400px，避免加强俯仰时露出旧 941px 画布的裁切边。地面、底座、人物、城市、远景云因此产生各自的视差。遮罩尺寸、云流体参数沿用 v6。

## 原站粒子

来源是归档的公开 `CfE0pqJa.js`，原作者与 bundle hash 见 `HomeOriginalShaders.ts` 和 `public/home-original/SOURCE.md`。

- **YJ 星点：246 个**，原 `OJ/BJ` 着色器、`night-star` 贴图，随距离改变大小，转动与闪烁。
- **FJ 萤火光点：40 个**，原 `AJ/VJ` 着色器、`night-firefly` 贴图，三轴漂浮；实际采样流体浓度改变光点大小和颜色。
- **JJ 烟花：512 个/次，5 个复用池**，原 `qJ/KJ` 着色器，球面初速度、Power4 上升与扩散、后半段下落和生命衰减。五个池对应原站低档配置。自动分左右与中心错峰触发，空白区域鼠标松手也触发。

自有场景的单位比原站大约 227 倍，因此对坐标、振荡与距离衰减中的尺寸作单位转换；不是把原 shader 直接套在像素坐标上。星点的远景深度约 -9000，因此相机 far 扩展到 20000。为便于比较，初始分布和烟花随机数采用固定序列。

原烟花的 CPU 更新对已经死亡的粒子仍继续计算；移植版停止更新这些粒子并将其大小归零。调度放在当前场景的 update 中，不创建额外定时器；返回首页会清空烟花并重新启动错峰调度。“减少动态效果”时停止自动/点击发射并冻结漂浮闪烁。

点击位置从当前透视相机反投影，烟花起点跟随鼠标像素。按钮和链接不触发烟花，转场期间不接收发射。粒子在内景 target 中先渲染，再通过原遮罩裁切，前景云最后叠加。

## 验证

用同一个桌面鼠标操作前后比较：v6 在右侧位置测得相机 Y 旋转约 -0.069rad，v7 同位置约 -0.178rad；对应主角锚点约 x603px、城市中心 x548px，存在约 55px 的前后层偏移。左右移鼠时，相机旋转和前后偏移方向均反转。

实测数据和最终检查见 `verification.json`。截图：`desktop.png`、`left.png`、`right.png`、`click-burst.png`、`production.png`、`mobile.png`、`mobile-works.png`。本轮针对视觉交互使用真实浏览器反馈与 TypeScript/Vite 构建检查，没有额外添加浅层公式单元测试或声称测得真机帧率。

修改入口：镜头与图层深度在 `HomeAiScene.ts` 顶部与 update 中；粒子系统在 `HomeReferenceParticles.ts`；原始着色器保存在 `HomeOriginalShaders.ts`，适配仅在调用处完成；地面绘制在 `HomeAiStage.ts`。
