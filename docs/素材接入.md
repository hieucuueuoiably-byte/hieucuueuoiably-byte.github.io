# 真实素材接入

素材源目录：`I:\xiaazai\zpj\0.001\zucai`。递归纳入全部 **18 条视频**：根目录 7 条影像作品，`带货预热视频` 子目录 11 条。18 条都含音轨；16 条竖屏、2 条横屏。

原片保留在源目录，未修改。网页副本位于 `public/videos/{slug}.mp4`，统一为 H.264、yuv420p、AAC 和 faststart；竖屏 594×1056，横屏 1920×1080，保持原始比例。原片合计 1,587,055,339 字节，网页视频合计 141,760,749 字节，减少 91.07%。

每条作品从原视频抽取 5 个候选帧，人工选帧后生成 `public/covers/{slug}.jpg` 与 `public/media/{slug}-poster.jpg`。方形封面为 1024×1024；剧情片围绕主体裁切，带货片保留完整画幅并加纯色衬底；poster 保持视频比例。未生成新的艺术图片。

保留的真实影片预览素材取自 `9月3日 (2).mp4`：`public/media/hero-still.jpg` 与 `public/media/hero-preview.mp4`，后者为 12 秒静音预览，约 1.13 MiB。当前首页采用此前生成的影院角色分层插画，位于 `public/home/`；首页转场捕获实际插画页面，影片预览素材没有作为首页主视觉。

改作品名称、顺序、简介或分类，只需编辑 `src/data/works.ts`。当前名称依据源文件日期与类别，职责及制作过程留空；`sourceFile` 对应原片，`poster` 对应真实抽帧。`themeColors` 轮换使用参考站五套鲜艳色对，属于页面设计取色，不代表影片自身颜色。

溯源与验收见 `docs/media-manifest.json`，包含每条原片路径、实测时长/比例/编码/音轨、候选帧时间、选帧、网页编码信息与验证结果。联系表位于：

- `public/media/contact-sheet-films.jpg`：7 条影像作品的候选帧。
- `public/media/contact-sheet-previews.jpg`：11 条带货预热的候选帧。
- `public/media/contact-sheet-covers.jpg`：全部已选封面。

核对媒体：`python -X utf8 scripts/verify_portfolio_media.py`。此命令检查现有媒体并更新清单内的验收记录，不转码、不改原片。
