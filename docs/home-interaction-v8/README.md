# 首页 v8 · 气球、云量与舞台透视

按本轮要求扩大遮罩、增加云量，让气球明显运动，并进一步加强鼠标移动时的舞台透视。沿用现有角色和气球素材，由代码驱动动画。

| 项目 | v7 | v8 |
| --- | --- | --- |
| 桌面遮罩系数 | 0.93 | 1.00，约增加 7.5% |
| 手机遮罩系数 | 0.89 | 0.95，约增加 6.7% |
| 前景 WebGL 云 | 40 个 | 64 个，两排错位，中心留出舞台 |
| 城市后方远景云 | 3 朵 | 6 朵 |
| 气球 | 小幅上下晃动 | 三个气球以 20 / 23 / 26 秒错峰升起、摇摆、前后浮动 |
| 气球循环 | 无 | 两端渐隐，上方消失后从下方重新出现 |
| 气球绳 | 简单左右波动 | 按旋转后的气球绳结定位，随风速弯曲、拖动，透明度与气球同步 |
| 桌面镜头横移 / 纵移 | 320 / 170 | 450 / 235，约增加 40% |
| 桌面注视点横移 / 纵移 | 100 / 65 | 140 / 90 |
| 城市 / 天空深度 | -1000 / -1600 | -1250 / -1900 |
| 左 / 右角色深度 | 260 / 360 | 310 / 430 |
| 底座绕 Y 轴的鼠标旋转系数 | 0.13 | 0.20 |

前景云继续使用原站的云形着色器、弹簧排斥和有界流体扭曲，独立于橙色舞台遮罩渲染。增加的第二排集中补足两侧和下方，不把中间的角色完全遮住。星点、萤火光点和自动/点击烟花保留 v7 实现。

气球循环使用独立时间，重新进入首页时复位。循环开始与结束时渐隐，避免回到底部的跳变。减少动态效果时不再上升、摇摆或转动；气球绳保持静止。无 WebGL 的静态首页同步增加远景云、前景云和遮罩尺寸。

## 浏览器验证

实际截图和 DOM 状态保存在本目录，完整数据见 `verification.json`。桌面左右移鼠分别记录约 -0.306 / +0.306 rad 的相机 Y 旋转；主角和城市中心相距约 108 px，且偏移方向随鼠标方向反转。两次保持鼠标不动的气球采样用于核对自主上升，而不是只靠鼠标带动。

`npm run build` 通过，生产包为 `index-CF0aHmFh.js`。开发与生产两套浏览器均载入 v8、无控制台错误；375×812 手机视口的文档宽度为 375，没有横向溢出，进入作品和返回首页正常。遮罩尺寸、云数量、左右相机方向、100 px 以上的前后视差、气球自主运动及绳子坐标有限值等 13 项记录均通过。减少动态效果与无 WebGL 静态版的本轮改动做了代码检查，未另行切换浏览器环境实测。

## 调整位置

- `src/gl/HomeAiScene.ts`：遮罩尺寸、相机、深度、气球升起/摇摆与绳子。
- `src/gl/HomeForegroundClouds.ts`：64 个前景云实例、两排位置、原站弹簧和流体响应。
- `src/gl/HomeAiStage.ts`：6 朵远景云的曲线路径和位置。
- `src/gl/HomeCodeFallback.ts`：静态降级版本。

原站来源和移植范围仍见 `public/home-original/SOURCE.md`。v8 的遮罩大小、云量、舞台深度和气球循环属于本作品集的调参，不作为原站实测数值。
