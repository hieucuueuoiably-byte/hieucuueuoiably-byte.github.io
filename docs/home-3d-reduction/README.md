# 鼠标 3D 随动减弱

用户明确要减少 3D 随动；未指定百分比，本轮采用已说明的默认值：减少 30%，保留上一版 70% 的幅度。

`src/config/homeMotion.ts` 的 `HOME_POINTER_3D_GAIN = .7` 统一控制首页镜头、底座、角色与气球的鼠标倾斜，以及顶部文字的鼠标视差。减少动态效果仍可以关闭这些交互。

| 项目 | 上一版 | 当前 |
| --- | --- | --- |
| 桌面镜头最大横移 / 纵移 | 450 / 235 | 315 / 164.5 |
| 桌面注视点最大横移 / 纵移 | 140 / 90 | 98 / 63 |
| 底座鼠标 Y 旋转系数 | .20 | .14 |
| 进入作品悬停时推近 | 7.5% | 5.25% |
| 进入作品悬停时 FOV 变化 | 5° | 3.5° |
| 标题鼠标最大横移 / 纵移 | 8 / 4 px | 5.6 / 2.8 px |
| 标题鼠标最大 X / Y 旋转 | 3 / 5° | 2.1 / 3.5° |

百分比作用于鼠标运动幅度。现有深度布局、气球自主运动、前景云流体、粒子、文字入场与导航交互沿用此前设置。

构建通过，生产包为 `index-8YPaCoig.js`。实际浏览器结果、同位置鼠标测量及截图见本目录的 `verification.json` 和 PNG 文件。

1280×720 的同一鼠标位置（1030,275）下，相机 Y 转角由 -0.3059 rad 降为 -0.2178 rad，约 17.5° → 12.5°。标题横移为 3.4125 px，符合旧 4.875 px 的 70%。鼠标返回屏幕中心后相机回正；开发、生产浏览器均无控制台错误，生产页面确认载入新构建与 0.7 强度。
