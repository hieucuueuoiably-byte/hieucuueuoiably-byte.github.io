这一项上做过一次纠偏：早期版本把几何弯曲当成主要表现手段，结果封面被搅成漩涡、轮廓都不方了 —— 而参考站其实是"轮廓不动、内部有波纹"。现在把权重改成 几何位移很小（≤2%）+ UV 位移中等（约 1.2%）+ 法线高光为主要可见通道。 另外发现 maxBend 这个参数当时根本没参与运算（uBend 直接吃了归一化的 ±1）， 所以怎么调都没反应 —— 已修，现在改参数会真的生效。

上次位置记忆localStorage['last-chapter']localStorage['portfolio:last-work']已复现
为什么加"输入静默期"：参考站只用「渲染速度 < 0.1」判断停稳，但这个条件在两次滚轮事件之间 就会被满足 —— 于是每次事件刚累加的位移立刻被吸附回去，无法累加。而「单次 120 不动、五次 120 走一格」 恰恰依赖"能累加"。所以成品改成"最后一次输入之后静默 130ms 才允许吸附"， 语义等价（手势停下来才吸到最近一格）且与帧率无关。

顺带作废一个旧结论：v2 报告里写的「滚轮累计阈值 = 140（observed）」是错的 —— 那是从"单次 120 不动、五次 120 走一格"这一个观测点推出来的，既不能证明阈值存在、也定不出大小。 实际参考站没有阈值；「120 不动」是因为位移不足半个格子。

结论汇总

类别项
已复现 顶栏胶囊选中态/hover 数值、顶栏换色（含首页 600ms 延迟）、两侧链接定位、首屏加载层、 滚轮输入公式（连续累加、无阈值、无冷却）、二阶阻尼 smoothTime 100/200、越界顶回 40、 四组吸附时长与缓动、速度时间窗、键盘映射、localStorage 记忆、首尾 clamp、 风扇布局四个数值（边长比 / 缩放 / 偏移 / 旋转）、邻封压暗、 背景双色 + 硬边大圆 + 颗粒采样保持、UV 位移的 vUv.y 加权结构、 关于页定位点与进度条数值、色板
已适配 内容模型（漫画 → 影像作品集）、进入作品的海报接续、跨路由共享控制条、视频比例与播放控制、 触屏/键盘输入、返回恢复位置、首页分层舞台、关于页文字分段的实现方式、 形变通道的权重分配（法线高光替代法线贴图）
待验证 转场的精确时长与缓动曲线（参考站在 WebGL 内完成，DOM 采样不到）、 阻尼系数与弯曲幅度的标定、关于页视差倍率、停止后的形变收敛曲线、 真机 GPU 帧率（本机只有软件渲染）
