## 本轮修正

- 旧渲染器错误把漫画阅读的纸张弯曲套在目录上，替换为刚性专辑盒与塑料材质。
- 旧整屏云幕换成双 RenderTarget 合成；首页使用实际页面捕获。
- 导航 `snap()` 清理旧补间后重置新目标，导致快点下一件漏一格；清理后重新写入目标。
- 竖屏视频被旧舞台高度与固定条布局顶出视口；舞台预留顶栏和播放条空间。
- 指针拖动误用起始 X 比较纵向距离；补充 startY，并在取消或纵向意图时避免触发横移。
- 进度条支持持续拖动，播放器加入全屏与错误重试；视频 effect 清理保留 React 管理的 src。
- 窄屏首页缩小侧面角色并重新安排中央角色，降低拥挤；影片封面反光减弱，保持人物可读。
