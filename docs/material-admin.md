# 个人素材后台

后台在你的电脑上运行，地址为 **http://127.0.0.1:5230/**。GitHub Pages 继续托管公开网站。已有作品保留，新上传的作品按顺序追加。

## 打开与登录

双击项目根目录的 `启动素材后台.cmd`，或在项目目录运行 `npm run admin`，浏览器会自动打开后台。

点击「连接当前 GitHub 账号」使用这台电脑已有的 GitHub 登录。如果尚未登录，点击「在 GitHub 登录」，在 GitHub 打开的页面完成登录。只有网站仓库所有者 `hieucuueuoiably-byte` 可以管理素材。凭证通过本机 Git 凭据管理器保存，不写入网页、作品数据或 GitHub 仓库。

需要本机安装 Node.js（包含 npm）、Git、Git Credential Manager、ffmpeg 和 ffprobe。当前这台电脑已具备这些工具。关闭浏览器后后台仍可运行；再次双击启动文件会复用现有服务。

## 日常操作

1. **作品库**：搜索作品，按分类或上架状态筛选；点击封面在本机预览视频。
2. **编辑作品**：修改名称、分类、描述、标签。关联图片取消勾选后会从网站隐藏，重新勾选即可恢复。
3. **上传素材**：上传视频并填写名称、分类，可同时添加参考图片；也可以单独给已有作品添加图片。
4. **下架 / 重新上架**：调整展示状态，作品记录、原视频和图片仍保留。下架视频不会进入新发布的网站文件。
5. **修改记录**：可恢复某条记录修改前的内容，其他作品不受影响。撤销新增视频会将其下架。
6. **发布到网站**：检查素材、生成网页、提交到 GitHub，再等待 GitHub Pages 部署完成。发布成功后网站才会展示最新内容。

「保存修改」和「发布到网站」是两步。后台显示的是本机保存的版本；有修改时会提示「待发布」。发布任务进行期间暂停上传与编辑，避免内容混在同一次发布中。

## 文件与去重

- 原始上传文件和修改记录保存在 `.admin-data/`，此目录已加入 Git 忽略，不会发布。
- 视频生成 H.264 / AAC 的 MP4，使用 faststart，保留完整时长和原画幅，同时生成封面和播放前的静帧。
- 原视频最大 2 GB；网页版本小于 50 MB。较长视频如果无法满足大小限制，会提示拆分，不会替换已有作品。
- 每次可关联最多 40 张图片，每张最大 25 MB，生成网页图片及缩略图。
- 视频按文件内容的 SHA-256 识别重复，匹配已有作品时不追加。同一张图片不会重复关联到同一作品。
- 去重针对相同文件内容；不同编码、加字幕、重新剪辑的版本可作为不同作品保留。

作品数据在 `src/data/works.ts`，新增素材在 `public/videos`、`public/covers`、`public/media`、`public/materials`。下架只改变展示状态，不永久删除仓库中的源文件。

## 发布异常

发布失败后，原文件和本机修改仍保留，可处理错误后重新发布。后台会检查仓库、分支和 GitHub 最新版本。项目中如果有后台以外的未提交代码修改，先处理代码再发布，避免误提交。网站仓库有其他更新时，先同步项目后再重试。

发布需要网络能够访问 GitHub。这个后台负责内容管理，视频上线后仍由当前 GitHub Pages 提供，国内网络的播放速度取决于托管线路。

## 检查

`npm run verify:admin` 在独立临时目录测试登录与请求来源、下架恢复、原作品保留、视频转码、文件去重和网站生成，不修改真实作品。GitHub Actions 也会执行这些检查。
