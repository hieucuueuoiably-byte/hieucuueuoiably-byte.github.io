# 首页角色破面修复 · 2026-10-01

原因是透明素材遮罩：旧颜色阈值与小组件剔除删掉了阴影、细关节和黑色道具；矩形 ROI 裁断章鱼触手和鞋子。遮罩本身已经有洞，静止时即可复现。旧眼睑位置与拍板变形范围也覆盖了部分脸部。

修复保留批准的源图像素：中央角色按闭合墨线选取区域，补回肩膀、手臂、围巾、胶片轮边缘和鞋子；章鱼移除触手的矩形裁切，保留小面积吸盘/阴影；绿色角色恢复耳机、原图连续脖子、麦克风杆接头、设备包和线缆，去掉重复代码补画的脖子/杆。气球遮罩中心和绳子连接点重新对齐。

形变的手臂权重在脸部轮廓前衰减；拍板的矩形权重移除，避免同时拉动脸颊；鸟头权重避开高处麦克风。重新校准眼睛/镜头位置，眼睑只作用于原图眼白和瞳孔像素，不再往肤色上画圆块。人物呼吸、挥手、触手、漂浮、流体波纹和镜头交互继续保留。
