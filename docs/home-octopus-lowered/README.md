# 左侧章鱼再次下移

章鱼沿同一水平地面向前移动，深度 310 → 350；深度补偿保持正面尺寸，1280×720 时支撑点在画面中约下移 14 像素。地面和右侧角色的位置不变，章鱼的贴地阴影同步移动。静态降级共用此深度参数。

鼠标 3D 随动强度由 0.49 调至 0.343，精确减少当前幅度的 30%。参数分别位于 `src/gl/HomeAiStage.ts` 和 `src/config/homeMotion.ts`。

构建通过，生产文件为 `index-DMCUOMxn.js`。实际生产首页正面和右转检查通过，支撑点高度差均为 0，阴影距支撑点 0.020，控制台错误为 0。证据：`desktop.png`、`tilt.png`、`captures.json`。本轮未单独进行手机浏览器验收。
