# 首页顶部文字 v9

站名改为一行“作品集网站”，从 `SITE.name` 读取；取消旧版 0.78 行高造成的上下两行挤压。标题、副标题居中对齐，副标题两侧增加细分隔线。两个小星标沿用首页奶油色，六秒循环缩放和转动。

“作品”和“关于”统一为 44 px 高的交互区域，文字在同一条基线上。桌面两侧导航区域围绕屏幕中线对称，手机两侧贴边。分类菜单及键盘焦点保持原有交互。

加载完成后五个字按 55 ms 间隔翻入，单字动画 850 ms；随后副标题浮现、分隔线展开。鼠标移动时标题最多平移 8 / 4 px、绕 X / Y 轴转动 3 / 5 度，以 650 ms 缓动跟随；移出页面或窗口失焦时回正。导航悬停及键盘聚焦时，文字上浮 2 px。

动态效果与入场均使用现有 GSAP 和 CSS；监听器与补间随首页卸载清理。减少动态效果时显示静止标题、关闭星标动画与鼠标跟随。没有新生成素材。
