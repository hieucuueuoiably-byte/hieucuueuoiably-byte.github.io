# 视频分类与二级导航

作品目录采用“分类封面 → 分类内左右切换 → 点击原地播放”的结构。根目录仍显示三个分类节点，18 个真实视频分布在对应的二级目录中。分类内保留原有左右轮播，只把统一的正方形封面改为影片原比例；点击当前作品直接在当前舞台播放，无需再进入详情页。

| 分类 | 视频数 | 二级目录 |
| --- | ---: | --- |
| AI 短片 | 5 | `/works/category/ai-shorts` |
| 动画影像 | 2 | `/works/category/animation` |
| 带货预热 | 11 | `/works/category/product-previews` |

## 页面与返回关系

- `/works`：三个分类封面。点击当前封面或控制条“查看分类”进入该分类。
- `/works/category/:category`：在当前分类内左右切换视频，保留滚轮、拖拽与前后切换的浏览方式。点击当前画面或播放按钮，在同一分类页面、同一舞台原地播放，URL 不跳转到额外详情页。
- 视频和静帧保持原比例：横屏按 16:9、竖屏按 9:16 展示，不拉伸为统一的正方形封面；分类内采用当前作品与邻近作品的左右展示方式。
- 切换到另一件作品或离开分类时，停止原来的视频，播放控制只操作当前作品。
- `/works/:slug`：保留单个视频的详情深链，例如 `/works/film-0903-02`。已有视频链接仍可直接打开播放器。
- 保留的详情播放器上一件、下一件只在当前分类内切换；返回后回到对应分类。
- 分类页和详情页的面包屑可回到三个分类的根目录。
- `/works/` 与 `/works` 都属于分类根目录；未知分类标识重定向到 `/works`。

分类封面直接复用真实视频的封面帧：AI 短片使用 `film-0824`，动画影像使用 `film-0903-02`，带货预热使用 `preview-0928-164227`。分类节点本身没有视频，不会进入播放器。

## 修改现有分类

分类配置位于 `src/data/categories.ts`，真实视频配置仍在 `src/data/works.ts`。

1. **把视频移入其他分类**：修改该视频的 `category`，使用当前精确标签之一：`AI 短片`、`动画影像`、`带货预热`。分类视频数和根节点的数量说明由数据自动计算。
2. **修改分类介绍**：修改 `collections` 中的 `description`。根分类封面和控制条会使用新介绍。
3. **更换分类封面**：把 `collections` 中的 `coverSlug` 改成一个真实作品的 `slug`，即可复用那件作品的封面。应选择对应分类中具有代表性的画面。
4. **重命名分类**：同时修改 `collections` 的 `label`、`scopedWorks` 中的筛选字符串，以及该分类所有作品的 `category`，保持三者一致。保留 `id` 可继续使用现有链接。
5. **更改分类地址**：修改分类 `id` 时，也要同步 `WorkCategoryId` 与 `scopedWorks` 的键。旧地址不会自动保留，外部链接需要一起更新。

同一分类内的视频顺序由 `WORKS` 中的原始顺序决定，视频的 `no` 仍是原作品编号。原比例展示由 `videoAspect` 控制，分类内静帧使用 `poster`；分类根封面继续使用方形 `cover`。浏览与播放需采用同一比例，避免点击播放后改变画面形状。

## 增加分类或视频

新增视频时，在 `WORKS` 中填写唯一的 `slug`、视频路径、封面路径与正确的分类标签，视频文件放到 `public/videos/`，封面放到 `public/covers/`。保持视频原比例的抽帧可放到 `public/media/` 并填写 `poster`。

新增分类需要在 `WorkCategoryId`、`collections` 和 `scopedWorks` 中加入对应项，再把作品的 `category` 设为该分类的精确标签。分类节点、数量与 `/works/category/:category` 路由由配置生成，不需要为每个分类建立单独页面。`coverSlug` 必须指向存在的真实作品。

## 导航与素材约定

根分类封面与二级分类内的视频都保留左右横移交互。二级分类当前作品按原比例显示，真实视频在同一舞台原地播放；浏览静帧和视频播放切换时保持位置与画幅一致。

导航区分“分类内位置”和“真实作品身份”；分类数据来自同一个 `getWorksForCategory` 列表。分类目录和保留的详情深链使用同一套作品身份映射。独立记忆键为 `portfolio:last-work:<分类 id>`，根分类使用 `portfolio:last-work:all`。

WebGL 不可用时，分类与作品可使用静态画面浏览，真实视频仍可原地播放。首页与根分类之间继续使用原有转场编排。

本文记录当前结构和维护方法，不作为浏览器测试通过的证明；实际检查结果由本轮验收单独记录。
