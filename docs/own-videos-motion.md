# 真实视频版动效说明 · 2026-09-30

参考：[Ponpon Mania](https://ponpon-mania.com/)。公开前端提取记录位于 `../../ponpon-public-source/excerpts/home-transition.md` 和 `pager-cover.md`。当前项目是 React / Three.js 对其公开视觉机制的作品集适配，参考站自身使用 Nuxt / OGL。

## 首页

背景、左右角色、中央角色、前景分别使用同坐标画布的透明分层图，来自此前生成的影院主题素材。本轮没有重新生成插画。GSAP 编排独立缩放、位移、旋转与弹性入场，加载层结束后播放；指针移动通过不同强度的缓动位移产生视差。375 px 窄屏使用独立角色缩放与位置，保证中央兔子完整可见，左右角色在两边露出。

## 首页与作品目录

真实首页 DOM 先转成纹理，旧画面与目标目录渲染到两个 RenderTarget。合成着色器使用中心圆形揭示和桶形 UV 变化；第一阶段 1 s、第二阶段 1.5 s，第二阶段延迟 0.05 s，均为 `expo.inOut`。目录专辑同时弹性入场，DOM 控制条最后显现。

目录返回首页使用波浪矩形遮罩；两阶段各 1 s，第二阶段延迟 0.1 s。返回首页先挂载完成状态再捕获，避免捕获未入场的角色。首入与返回后的再次进入均检查了首页纹理绑定，没有将影片静帧当成转场旧画面。

播放器与关于页采用中央圆形遮挡的 DOM 转场，属于内容适配。减少动态效果时缩短遮挡时间并停用装饰动画。

## 作品目录

| 项 | 当前机制 |
| --- | --- |
| 专辑 | `BoxGeometry(1, 1, 0.02)`，刚性薄盒 |
| 相机 | 45° 透视，桌面 z=5，窄屏过渡至 z=8 |
| 排布 | pitch=1.9；相对位置 u；z=1.1−0.4×abs(u)，rotY=−0.45u，rotZ=−0.1u |
| 输入单位 | 控制器以作品下标为单位；参考世界单位 `(deltaY+deltaX)/400` 换算后除以 760 |
| 拖动 | 像素位移乘 0.005/1.9；判定水平意图后跟随，抬手吸附 |
| 边界 | 首尾限制在 0…17；按钮、滚轮、键盘共用导航状态 |
| 材质 | 塑料法线图、0.004 UV 偏移和 5 s 周期扫光；影视封面白色反光权重降低到 0.075 |
| 背景 | 径向双色底色、颗粒、独立圆层与纹理色带；换片后跟随作品主题色 |
| 点击 | 中央封面开启影片；拖动超过 8 px 抑制误点 |

先前的“分段平面纸张弯曲”来自参考站漫画阅读场景，当前目录已移除。全站完整流体模拟未移植，圆层指针扰动为近似；未宣称帧率或真实手机 GPU 性能与参考站完全相同。

## 播放与滚动

播放器保留 9:16 / 16:9 原画幅，舞台为顶栏和固定播放条预留空间。控制条跨路由共用，播放器增加进度和全屏。React 管理 `src`，effect 清理只暂停、重置控制器与解除监听，不移除 `src`，支持开发 StrictMode。

关于页使用文档滚动、ScrollTrigger 文字显现与色块视差，向上滚动可回退。键盘作用域为目录 / 播放器 / 内容页三档；进度条自己处理 Home、End、左右键，不触发切片。
