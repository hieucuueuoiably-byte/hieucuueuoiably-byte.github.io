# 首页交互 v6 · 2026-10-02

本轮处理：遮罩略放大、前景云增加流体拖尾、舞台增加真实透视运动。角色继续使用现有代码曲线与关节部件，未重新生成图片。v5 的实现与截图保留为历史记录。

## 变更

| 项目 | v5 | v6 |
| --- | --- | --- |
| 桌面遮罩系数 | 0.86 | 0.93，增加约 8.1% |
| 竖屏遮罩系数 | 0.84 | 0.89，增加约 6.0% |
| 内景镜头 | 正交，无旋转 | 45° 透视，鼠标控制相机位置与 lookAt，160ms 阻尼 |
| 角色深度 | 三个角色均 z=0 | 主角 0、章鱼 135、鸟 220；城市 -650、远景云 -950、气球 -160 |
| 底座 | 印在平面上的假顶面 | 365×126×100 的真实盒体，独立顶面、侧面与轮廓线 |
| 流体染料保留率（60Hz） | 0.9 | 0.965 |
| 流体速度保留率（60Hz） | 0.2 | 0.92 |
| 涡流强度 | 2 | 8 |
| 前景云流体采样 | 原站位移倍率 | 1.5 倍，使用平滑限幅，单轴 UV 极限 0.055 |

深度补偿以 `(cameraZ-z)/cameraZ` 调整中立视角下的尺寸和位置，保留批准的角色站位。鼠标移动时，透视投影产生不同层的真实视差，不再把所有素材一起平移。底座正面继续使用原有代码绘制的镜头图案，假顶面从动态图中移除，静态降级仍保留。

前景云仍是原站的 40 个实例、鼠标排斥、弹簧回弹和独立描边渲染。涡流、压力投影和染料平流负责轨迹拖尾；静态实例位置和流体 UV 扭曲是两条独立链路。云使用独立透视相机，不跟着内景镜头转动；远景云在城市后方单独漂移。

延长流体寿命后，原遮罩 shader 的绿色通道偏移会造成角色重影，因此给角色色偏增加约 1.3 像素（1280 宽视口）的上限；遮罩自身位移也作平滑限幅。全场景额外液化与色散已移除，前景云保留主要的流体形变，点击波纹仍保留。

这些参数是本作品集的调整值，并非对原站时长、幅度或性能的完全等同声明。原站 GLSL 与纹理来源见 `public/home-original/SOURCE.md`，原始代码保留在 `HomeOriginalShaders.ts`，适配与限幅在调用处完成。

## 实测

- 修改前实测：`OrthographicCamera`，三个角色深度 `0,0,0`，鼠标移动后相机旋转仍为 `0,0`。
- 修改后实测：`PerspectiveCamera`，角色深度 `0,135,220`，左右移鼠时相机 Y 旋转跨过零点；三个角色的屏幕坐标产生不同幅度的变化。
- 最终构建划过前景云：GPU 染料场测得云区最大位移约 65.8px；停止输入约 216ms 后仍有 61.2px，随后衰减至 0。该数值是低分辨率网格采样的场内最大位移，不等于所有云边缘同时移动的幅度。
- 生产版手机 375×812：遮罩 0.89，三个角色与入口可见，页面宽度与 scrollWidth 都是 375；进入分类并返回首页成功。
- 开发与生产的控制台错误均为 0；构建 `tsc -b && vite build` 通过。
- 本轮未额外测量真机帧率或系统减少动态效果模式。减少动态效果代码继续复用原有开关，未更改该交互约定。
